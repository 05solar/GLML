## 무엇을 만들었나

**GLML — 맛집 찾기 AI Agent.**
사용자의 조건(지역·동행·시간대·음식·가격·우선순위)을 분석한 뒤, **맛집 검색 도구를 직접 호출**하고
그 결과를 **검토(Reflection)** 하여 조건에 맞는 맛집을 추천하는 **Agentic AI** 시스템입니다.

단순히 LLM에게 "맛집 추천해줘"라고 묻는 것이 아니라, Agent가
**판단(Thought) → 도구 호출(Action) → 결과 확인(Observation) → 검토 → 최종 추천(Final Answer)**
흐름으로 동작합니다. 백엔드 ReAct Agent가 이 과정을 **실제로 실행**하고, 프론트엔드가 화면에 시각화합니다.

## 핵심 특징

| 항목 | 내용 |
| --- | --- |
| 필수 패턴 | **ReAct** (Thought → Action → Observation → Final Answer) |
| 추가 패턴 | Plan-and-Solve · Memory · Tool Use · Reflection (총 **5개**) |
| 도구 | `search_restaurants` · `filter_restaurants` · `rank_restaurants` (3종) |
| 데이터 | **Google Places API (New)** 실시간 → Kakao(지역검증)+샘플 → 샘플 폴백 |
| 예외 처리 | 지역 없음·결과 없음·음식 모호·API 실패·조건 부족 (Observation 기반 대안 제시) |

## 기술 스택

- **백엔드**: Python · Flask · OpenAI(gpt-4o-mini) · python-dotenv · requests
- **프론트엔드**: React 18 · TypeScript(strict) · Vite 5

## 프로젝트 구조

```
GLML/
├── backend/                  # ReAct Agent (Python)
│   ├── main.py               # CLI 진입점
│   ├── server.py             # Flask API 서버 (POST /api/recommend)
│   ├── agent.py              # Plan-and-Solve → ReAct → Reflection
│   ├── tools.py              # 도구 3종 + OpenAI function 스키마 + Google/Kakao 폴백
│   ├── data/restaurants.json # 샘플 맛집 데이터셋
│   ├── logs/trace_log.txt    # 실행 시 자동 생성되는 Trace
│   └── requirements.txt
├── src/                      # React UI (조건 수집 + Trace 시각화 + 결과)
├── docs/                     # 제출 문서 (이 폴더)
├── package.json · vite.config.ts
└── README.md
```
