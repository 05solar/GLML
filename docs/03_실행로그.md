# 3. 실행 화면 / 실행 로그

지정된 테스트 프롬프트를 실제로 실행한 화면과 로그입니다.
(단계별 구조 분석은 [05_ReAct_도구호출_Trace.md](05_ReAct_도구호출_Trace.md), 원본 파일은 [`../backend/logs/trace_log.txt`](../backend/logs/trace_log.txt))

## 실행 방법

```bash
cd backend
python main.py "전주 객사 근처에서 친구랑 저녁 먹기 좋은 맛집을 찾아줘. 너무 비싸지 않고, 리뷰가 좋은 곳 위주로 3곳 추천해줘."
```

- 실행 모드: **LLM 모드** (OpenAI `gpt-4o-mini` function calling)
- 데이터 소스: **Google Places API (New)** 실시간 데이터
- 실행 일자: 2026-06-09
