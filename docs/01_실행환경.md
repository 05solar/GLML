# 1. 실행 환경 / requirements

맛집 찾기 AI Agent는 **백엔드(Python)** 와 **프론트엔드(Node.js)** 두 부분으로 구성됩니다.
각각의 의존성과 설치·실행 방법은 아래와 같습니다.

## 필수 환경

| 구분 | 버전 |
| --- | --- |
| Python | 3.10 이상 (개발 환경: 3.12) |
| Node.js | 18 이상 |

## 백엔드 의존성 — [`../backend/requirements.txt`](../backend/requirements.txt)

```
openai>=1.30.0          # LLM (ReAct 추론 + function calling)
python-dotenv>=1.0.0    # .env 환경변수 로드
requests>=2.31.0        # Google Places / Kakao Local API 호출
flask>=3.0.0            # 프론트 연동용 API 서버
flask-cors>=4.0.0       # CORS 허용 (개발용)
```

### 설치

```bash
cd backend
python -m venv .venv

# 가상환경 활성화
#   Windows (PowerShell):  .\.venv\Scripts\Activate.ps1
#   macOS / Linux:         source .venv/bin/activate

pip install -r requirements.txt
```

## 프론트엔드 의존성 — [`../package.json`](../package.json)

| 구분 | 패키지 |
| --- | --- |
| dependencies | react 18.3, react-dom 18.3 |
| devDependencies | vite 5.4, typescript 5.6, @vitejs/plugin-react, @types/react, @types/react-dom, @types/google.maps, concurrently 10 |

### 설치

```bash
npm install
```

## 환경변수 (.env)

키는 `.env`에 보관하며 **git/제출물에서 제외**됩니다(`.gitignore` 포함). 템플릿(`.env.example`)을 복사해 사용합니다.

| 파일 | 키 | 설명 |
| --- | --- | --- |
| `backend/.env` | `OPENAI_API_KEY` | **필수**. 없으면 오프라인 시뮬레이션으로 동작 |
| `backend/.env` | `OPENAI_MODEL` | 선택 (기본 `gpt-4o-mini`) |
| `backend/.env` | `GOOGLE_PLACES_API_KEY` | 선택. 실시간 평점·리뷰·가격 |
| `backend/.env` | `KAKAO_REST_KEY` | 선택. 지역 실재 검증 |
| 루트 `.env` | `VITE_GOOGLE_MAPS_API_KEY` | 선택. 위치 화면 실제 지도 |

```bash
# 백엔드 키
cd backend && cp .env.example .env    # Windows: copy .env.example .env
# 프론트 키(선택)
cd ..     && cp .env.example .env
```

> 키 발급 방법은 [06_외부API_사용방법.md](06_외부API_사용방법.md) 참고.

## 실행 방법

### 통합 실행 (Windows, 권장)
```bash
npm run dev          # 프론트(:5173) + 백엔드(:8000) 동시 실행
# 종료: Ctrl+C  /  강제 종료: npm run stop
```

### 분리 실행 (macOS/Linux 또는 디버깅)
```bash
# 터미널 1
cd backend && source .venv/bin/activate && python server.py   # :8000
# 터미널 2
npm run dev:web                                                # :5173
```

### 백엔드 단독 CLI 실행 (Trace 생성)
```bash
cd backend
python main.py                 # 기본 테스트 프롬프트 실행 → logs/trace_log.txt 저장
python main.py --offline       # API 키 없이 동일 파이프라인 실행
```

> API 키가 전혀 없어도 `--offline`(또는 키 미설정 시 자동)으로 동일한 도구 파이프라인의 Trace를 생성할 수 있습니다.
